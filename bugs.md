## FRONTEND

### Критические

#### BUG-01 · Главная страница крашила из-за `http://` URL в `next/image`
**Страницы:** `/`  
**Статус:** ✅ Исправлено  
**Описание:** API возвращает медиа-URL вида `http://imbir.sino0on.ru/...`, а `next.config.ts` разрешает только `https://`. Runtime-ошибка Next.js, полный краш главной.  
**Фикс:** `src/shared/api/requests.ts` — хелпер `toHttps()` в `adaptClinic` и `adaptDoctor`.

### Средний приоритет

#### BUG-10 · Клиники показывали «0 лет опыта»
**Страницы:** `/clinics`, `/`  
**Статус:** ✅ Исправлено  
**Описание:** Поле `experience_years` отсутствует в API для клиник.  
**Фикс:** `src/entities/clinic/ui.tsx` — скрывать при `experience === 0`.

#### BUG-07 · Fallback при отсутствии/ошибке фото клиники
**Страницы:** `/clinics`, `/clinics/[id]`, `/`  
**Статус:** ✅ Исправлено  
**Описание:** При отсутствии или ошибке загрузки изображения показывался пустой серый блок.  
**Фикс:** `src/entities/clinic/ui.tsx` — `ClinicImageFallback`: градиент `#FFF2F0→#FFD9CC`, аббревиатура в оранжевом квадрате, название клиники. `onError` на `<Image>` в обоих вариантах карточки.

#### BUG-12 · «0 лет опыта» в модале выбора клиники при записи
**Страницы:** `/record`  
**Статус:** ✅ Исправлено  
**Фикс:** `src/views/record/ui.tsx` — добавлен guard `item.experience > 0`.

#### BUG-14 · Попап «Ваш город» появлялся при каждой навигации
**Страницы:** Все  
**Статус:** ✅ Исправлено  
**Описание:** Кнопка «Изменить» не вызывала `setCity()`, поэтому `isSet` оставался `false` в Zustand-сторе и баннер показывался снова.  
**Фикс:** `src/shared/store/cityStore.ts` — добавлен экшн `dismiss()` (устанавливает `isSet: true` без смены города). `src/features/city-confirm/ui.tsx` — `handleChange` теперь вызывает `dismiss()`.

#### BUG-16 · Секция «Интервью» у специалиста — 1 захардкоженная карточка
**Страницы:** `/specialists/[id]`  
**Статус:** ✅ Исправлено  
**Описание:** Массив `videos` был захардкожен с одним элементом, что давало пустой грид на десктопе.  
**Фикс:** `src/views/specialist-details/ui.tsx` — `useQuery` + `getBlogPosts({ page_size: 3 })`. Секция скрыта если API возвращает пустой массив (сейчас нет данных на бэкенде — секция не показывается).

### Высокий приоритет

#### BUG-08 · На странице клиники нет списка врачей
**Страницы:** `/clinics/[id]`  
**Описание:** Бэкенд возвращает `doctors_count: 25`, но нет способа получить список — `GET /api/doctors/` возвращает `workplaces: []` для каждого врача, эндпоинт `/api/clinics/{id}/doctors/` не существует.  
**Нужно:** Добавить `GET /api/doctors/?clinic_id={id}` или включить `doctors: [...]` в ответ `/api/clinics/{id}/`.

#### BUG-09 · Услуги без привязки к клиникам и без фото
**Страницы:** `/services`  
**Описание:** Все карточки услуг показывают «Клиника не указана», `0` рейтинг и плейсхолдеры вместо фото.  
**Нужно:** Заполнить данные: привязать услуги к клиникам, загрузить изображения.
